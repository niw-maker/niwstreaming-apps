# NiwStreaming: apps

Instaladores dos apps do **NiwStreaming**, o streaming caseiro da família. Este repositório guarda só os arquivos para baixar, que ficam nas [Releases](https://github.com/niw-maker/niwstreaming-apps/releases). Os apps se atualizam por aqui.

## Windows
1. Baixe o `NiwStreaming-x.y.z-win-x64.exe` da release mais nova e abra.
2. Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador", porque o app não tem assinatura paga. Clique em **Mais informações → Executar assim mesmo**.

## Linux (Fedora, Ubuntu e outros)
1. Baixe o `NiwStreaming-x.y.z-linux-x86_64.AppImage`.
2. Dê permissão para executar: botão direito → Propriedades → "Permitir executar como programa", ou `chmod +x NiwStreaming-*.AppImage`.
3. Abra com dois cliques.
   - No Fedora, se não abrir, instale o FUSE: `sudo dnf install fuse fuse-libs`.

## Como usar
- O app procura sozinho os servidores NiwStreaming na rede de casa. Clique no servidor e entre com o seu perfil e a senha dele.
- **Trocar de servidor** e **Atualizar o app** ficam no menu do seu perfil (canto de cima), dentro do app.
- **F11:** tela cheia.
